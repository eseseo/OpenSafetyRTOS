# ASIL 분해 전략에 따른 제품화 잔여 작업

2026-11-27 작성. 코드와 시험 결과의 기준은 `a5cb549`이며, 판매 기준 MCU와 보드는 미정이다.

## 제품이 보증할 기능

ADR-001은 **SafetyFunction ASIL-D(D) + FreeRTOS QM(D)** 구조를 채택했다. SafetyFunction은 고장을 검출하고 정해진 시간 안에 안전 상태를 집행하는 역할을 맡는다. FreeRTOS는 스케줄링과 IPC를 제공한다. 고객 안전 기능이 이 서비스 자체의 정확성에 의존한다면 해당 서비스에 대한 요구사항 할당, 설계 보증 및 평가 범위를 추가로 정의해야 한다. 출시 전에 고객 통합 매뉴얼에 이 경계와 사용 가정을 명시한다. 분해 논증에는 두 요소의 독립성과 공유 자원에서 발생할 수 있는 종속 고장에 대한 근거가 필요하다. [분해 결정 ADR-001](../../docs/ADR-001-decomposition-strategy.md) · [기능안전 개념 §5](FSC.md) · [사용 가정](AOU.md)

## 보드 선정 전 진행 순서

| 순서 | 현재 확보한 근거 | 남은 작업과 완료 기준 |
| --- | --- | --- |
| 1. 데이터 교환 | 메일박스가 페이로드 CRC, 시각, 스키마를 검사한다. QEMU에서 연속 오류 후 제어 정지를 확인했다. | 헤더와 페이로드의 무결성 범위, 메시지 식별자·순번, 재시작 시 재동기화 정책을 정의한다. 헤더 손상, 중복·누락, 순번 순환, 쓰는 도중 읽기를 주입해 각 경우의 수락·거부와 안전 상태 전이가 요구사항과 일치하는지 시험한다. |
| 2. 메모리·DMA 간섭 방지 | QEMU에서 비특권 태스크의 타이머 접근 차단을 확인했다. 호스트 시험은 DMA 요청의 출발지·목적지 범위 검사를 다룬다. | 태스크 전환 시 바뀌는 MPU 영역과 안전 모니터가 대조할 설정을 명시한다. 전환 전후의 메모리 접근 권한, 특권 커널이 보호 설정을 훼손했을 때의 검출, QM이 DMA 설정이나 통신 경로를 우회할 가능성을 시험·분석한다. |
| 3. 시간 간섭 방지 | QEMU에서 QM 임계 구역 중 안전 타이머 실행과 감시 루틴 정지 후 Watchdog 리셋을 확인했다. | SSR-002의 주기당 1회와 반 주기 갱신 조건을 일치시킨다. 감지·판정·출력에 허용되는 시간을 배분하고, 인터럽트 지연과 태스크 정지 시험에 판정 기준을 적용한다. 실기 최악 반응시간은 별도로 측정한다. |
| 4. 검증 근거와 독립 검토 | 호스트 시험 10개, QEMU 시험 7개가 통과했다. 호스트 MC/DC는 85/85, 분기 결과는 272/284이다. | 미실행 분기 결과 12개를 시험하거나 사유를 검토한다. ARM 전용 코드·HAL·어셈블리의 검증 방법을 정한다. 요구사항별 설계·코드·시험 결과를 연결하고 FFI 분석서와 FMEA를 완성한다. Safety Case OP-006~008에 실제 증거와 남은 검토 범위를 반영한다. |

상세 수치와 재현 명령은 [구현 공백 및 검증 기준](IMPLEMENTATION_GAPS.md), 미확정 임계값과 시간 예산은 [소프트웨어 안전 요구사항 §6](SSRS.md), 독립 검토 현황은 [Safety Case](SAFETY_CASE.md)에서 추적한다.

## 제품 보드 선정 후 확보할 증거

- **시간과 안전 출력** — 최악 부하에서 고장 발생부터 물리적 안전 출력 전환까지 측정한다. 출력 피드백과 측정 오차를 포함해 통합자가 배정한 FTTI 예산을 충족하는지 판정한다.
- **클록·전원·리셋** — 독립 시간 기준과 Watchdog, 저전압 검출, 리셋 원인 식별, 전압 강하 후 이력 보존을 검증한다. 현재 QEMU 타이머와 Watchdog은 모델 클록을 공유한다.
- **제품 구성과 평가** — MCU·보드·컴파일러·빌드 옵션·FreeRTOS 버전을 고정한다. 제품 링커 맵, 실제 DMA 제어권과 메모리 보호, 부팅 자가시험의 메모리 범위를 확인한다. 고객 통합 매뉴얼과 인수시험, 도구 적격성 근거, 독립 검토·안전 감사·평가 결과를 해당 구성에 연결한다.
